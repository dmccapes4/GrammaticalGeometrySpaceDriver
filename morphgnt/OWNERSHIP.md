# MorphGNT — Vendored Snapshot

**Vendored:** 2026-11-03  
**Owner decision:** Dylan McCapes — "we need to own MorphGNT; we cannot allow drift"

## What is here

Three upstream repos from the `morphgnt` GitHub org, captured as a vendored snapshot
(`.git` dirs stripped, files committed into GGSD directly):

| Dir | Upstream | License | Description |
|---|---|---|---|
| `sblgnt/` | `morphgnt/sblgnt` | CC BY-SA 3.0 (data) + SBLGNT EULA (text) | SBLGNT text + MorphGNT morphological tagging. 27 NT books as `.txt` files. |
| `python/` | `morphgnt/py-sblgnt` | unknown | pip-installable Python API for reading the sblgnt data |
| `lexicon/` | `morphgnt/morphological-lexicon` | unknown | Lexeme YAML, derivation YAML, per-lexicon missing-word lists (BDAG, Mounce, Danker, Dodson) |

## Why vendored and not a submodule

A submodule would track the upstream remote. Upstream may:
- Change lemma assignments without a changelog
- Change normalization conventions
- Add or remove words from the missing-lexicon lists

GGSD requires stable, auditable input. Drift in MorphGNT lemmas is a direct bias vector
into the decoder. Vendoring pins the snapshot. All future updates are intentional and diffable.

## Bias analysis

See `probe_output/` — generated by `run_ai_probe.sh` using FullMetalPacket/ai_probe
with a custom config (`ai_probe_morphgnt_config.yaml`) focused on:

1. Textual-critical tradition bias (SBLGNT vs TR vs NA28 vs eclectic)
2. Lemmatization methodology and lexical authority
3. Morphological disambiguation conventions
4. Coverage gaps (missing_*.txt files)
5. Data fidelity — normalized vs surface form discrepancies
6. GGSD compatibility — numeral lemmatization, εἷς/ἓν specifically

## Key findings at capture time

- `missing_bdag.txt`: 83 lemmas including `κύριος` and `Σατανᾶς` — MorphGNT lemma form
  does not match BDAG headword exactly. Normalization mismatch, not absence.
- `missing_dodson.txt`: 203 entries — largest gap (Dodson is smaller lexicon).
- Parsing code comment in README: "Part of speech and parsing codes were inherited from
  the CCAT tagging and will be deprecated in the next major release." → provenance drift risk.
- SBLGNT text is under EULA (not CC) — the text itself is restricted; only parsing/lemma
  are CC BY-SA 3.0.
